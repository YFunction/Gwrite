# Gwrite - 机械臂毛笔字书写路径算法

## 项目简介

Gwrite 是一个基于机械臂的毛笔字书写路径算法设计项目。本项目旨在开发一套算法系统，能够将汉字转换为机械臂可执行的书写路径，实现自动化毛笔字书写。

## 项目特点

- **汉字数据支持**：包含完整的汉字数据集（hanzi_data），每个汉字都有对应的路径信息
- **G-code 生成**：支持生成 G-code 控制指令，用于驱动机械臂执行书写动作
- **可视化预览**：提供 G-code 可视化功能，便于验证路径算法的正确性
- **平滑配置**：支持对路径进行平滑处理，优化机械臂运动轨迹

## 安装与使用

### 依赖

- Python 3.x
- OpenCV
- NumPy
- Matplotlib

### 使用方法

1. 将要书写的汉字转换为 G-code：
   ```bash
   # 编译主程序
   g++ main.cpp -o main
   # 运行生成 G-code
   ./main
   ```

2. 预览 G-code 路径：
   ```bash
   python Gview/main.py
   ```
